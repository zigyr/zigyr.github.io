## 什么是SSTI？

`Server-Side Template Injection`服务器端模板注入

可能导致：

- 任意文件读取
- RCE（远程代码执行）
- 远程控制后台系统


## 漏洞成因

在渲染模板时：

- 没有严格过滤用户输入
- 使用了危险的模板渲染方式
- 导致用户可以与 Flask 程序交互

Flask 基于 Python 开发，如果用户能够与模板引擎交互，就可能执行 Python 代码，如：

- `eval`
- `system`
- `file`

等函数

## 安全示例
---

```python
from flask import Flask, request, render_template_string

app = Flask(__name__)


@app.route('/', methods=['GET'])
def index():
    str = request.args.get('ben')

    html_str = """
        <html>
        <head></head>
        <body>{{ str }}</body>
        </html>
    """

    return render_template_string(html_str, str=str)


if __name__ == '__main__':
    app.debug = True
    app.run('127.0.0.1', '8080')
```


`{{ str }}`

用户输入被包在 `{{ 变量 }}` 里 = **纯文本显示**

访问`127.0.0.1:5000/?ben=7*7`

先变成`{{"{{7*7}}"}}`，再交给`render_template_string()`去解析，安全


回显：

`7*7`

## 漏洞示例
---

```python
from flask import Flask, request, render_template_string

app = Flask(__name__)


@app.route('/', methods=['GET'])
def index():
    str = request.args.get('ben')

    html_str = """
        <html>
        <head></head>
        <body>{0}</body>
        </html>
    """.format(str)

    return render_template_string(html_str)


if __name__ == '__main__':
    app.debug = True
    app.run('127.0.0.1', '8080')
```



`str.format(str)`

用户输入直接变成 `{{ 代码 }}` = **被当作代码执行**


访问`127.0.0.1:5000/?ben={{7*7}}`

先变成 `{{7*7}}`，再交给`render_template_string()`去解析，危险

回显：

`49`

## SSTI 检测
---

常见检测语句：

```text
{{7*7}}
```

如果返回：

```text
49
```

则说明可能存在 SSTI 漏洞

问题本质：

- 用户提交的字符串未被严格过滤

- 模板引擎将输入当作代码执行

## 常见模板引擎特征
---


- `${7*7}`
- 正常执行
    - `a{*comment*}b`
    - 正常执行
	    - Smarty
    - 无法执行
	    - `${"z".join("ab")}`
	    - 正常执行
	        - Mako
	    - 无法执行
	        - Unknown
- 无法执行
    - `{{7*7}}`
    - 正常执行
	    - `{{7*'7'}}`
	    - 正常执行
	        - Jinja2
	        - Twig
		- 无法执行
	        - Unknown
	- 无法执行
	    - Not vulnerable
