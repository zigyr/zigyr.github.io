# 文件上传绕过 —— %00截断

## 核心原理

- **`%00`**：URL 编码中的空字节，在浏览器/URL 中被当作字符串结束标志

```txt

浏览器搜索"黑客"
https://cn.bing.com/search?pglt=129&q=%E9%BB%91%E5%AE%A2&cvid=6fb8e81ec7e249f6bf69a84c313aad86&gs_lcrp=EgRlZGdlKgYIABBFGDkyBggAEEUYOTIGCAEQABhAMgYIAhAAGEAyBggDEAAYQDIGCAQQABhAMgYIBRAAGEAyBggGEAAYQDIGCAcQABhAMgYICBBFGEHSAQgxNjYwajBqN6gCALACAA&FORM=ANSPA1&PC=U531
显示的页面是`黑客`

在中间添加`%00`
https://cn.bing.com/search?pglt=129&q=%E9%BB%91%00%E5%AE%A2&cvid=6fb8e81ec7e249f6bf69a84c313aad86&gs_lcrp=EgRlZGdlKgYIABBFGDkyBggAEEUYOTIGCAEQABhAMgYIAhAAGEAyBggDEAAYQDIGCAQQABhAMgYIBRAAGEAyBggGEAAYQDIGCAcQABhAMgYICBBFGEHSAQgxNjYwajBqN6gCALACAA&FORM=ANSPA1&PC=U531

显示的页面是`黑`

```

- **`0x00`**：编程语言中的空字节，类似 C/C++ 字符串中的 `\0`

> **环境要求**：PHP 版本 < 5.3（高版本已修复此漏洞）

## Pass-12 · GET 型 %00 截断

### 源码分析

```php
$ext_arr = array('jpg', 'png', 'gif');
$file_ext = substr($_FILES['upload_file']['name'],
 strrpos($_FILES['upload_file']['name'], ".") + 1);

if (in_array($file_ext, $ext_arr)) {
	$temp_file = $_FILES['upload_file']['tmp_name'];
	$img_path = $_GET['save_path'] . "/" . rand(10, 99) . date("YmdHis") . "." . $file_ext;

	if (move_uploaded_file($temp_file, $img_path)) {
		$is_upload = true;
	} else {
		$msg = '上传出错！';
	}
} else {
	$msg = "只允许上传.jpg|.png|.gif类型的文件！";
}
````

**白名单过滤逻辑**：

```php
$file_ext = substr(..., strrpos(..., ".") + 1);
```

从文件名中最后一个 `.` 之后截取后缀，与白名单 `['jpg', 'png', 'gif']` 比对

**漏洞点**：`$img_path` 拼接了 `$_GET['save_path']`，攻击者可控保存路径

### 攻击步骤

1. 上传一个图片木马 `111.jpg`
2. BP 抓包，修改 GET 参数 `save_path`：


```
?save_path=../upload/111.php%00
```

3. 服务端拼接后实际路径为：


```
../upload/111.php%00/随机数.时间.jpg
```

4. 因 00 截断，实际保存为 `../upload/111.php`，后缀 `.jpg` 被丢弃

5. 上传成功后访问 `/upload/111.php` 即可触发木马


> **注意**：上传成功后打开图像显示 Not Found，需将 URL 中的多余路径删除至 `/upload/111.php`

## Pass-13 · POST 型 %00 截断

### 源码分析


```php
$ext_arr = array('jpg', 'png', 'gif');
$file_ext = substr($_FILES['upload_file']['name'],
 strrpos($_FILES['upload_file']['name'], ".") + 1);

if (in_array($file_ext, $ext_arr)) {
 $temp_file = $_FILES['upload_file']['tmp_name'];
 $img_path = $_POST['save_path'] . "/" . rand(10, 99) . date("YmdHis") . "." . $file_ext;

 if (move_uploaded_file($temp_file, $img_path)) {
 $is_upload = true;
 } else {
 $msg = '上传出错！';
 }
} else {
 $msg = "只允许上传.jpg|.png|.gif类型的文件！";
}
```

与 Pass-12 逻辑相同，区别在于 `save_path` 从 `$_GET` 改为 `$_POST`

### 攻击步骤

1. 上传一个图片木马 `111.jpg`

2. BP 抓包，在 POST 请求体中找到 `save_path` 的值 `../upload`

3. 修改为 `../upload/111.php`，并在其后添加 **一个空格**

4. 在 Hex 编辑器中选中该空格，将其十六进制值改为 `00`

5. 效果与 GET 型一致：服务端路径被截断，文件保存为 `111.php`


> **POST 型与 GET 型的区别**：
> 
> - GET：直接在 URL 中写入 `%00`，浏览器会自动解码
> - POST：需要在 Hex 编辑器中手动将空格改为 `0x00`，因为 POST 数据不会自动进行 URL 解码
