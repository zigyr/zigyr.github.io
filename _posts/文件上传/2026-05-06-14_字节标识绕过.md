## 前置知识
---

| 文件格式      | 说明           | 头两个字节（Hex）  |     |
| --------- | ------------ | ----------- | --- |
| JPEG/JFIF | 常见图片格式       | `0xFF 0xD8` |     |
| PNG       | 无损压缩格式       | `0x89 0x50` |     |
| GIF       | 支持动画的图像格式    | `0x47 0x49` |     |
| BMP       | Windows 位图格式 | `0x42 0x4D` |     |
| TIFF      | 标签图像文件格式     | 数值不固定       |     |

- 英文字符：**1 字节**
- 中文（含繁体字）：**3 字节**


## 两个漏洞点
---

### 文件上传漏洞

```php
function getRealFileType($filename) {
    // 读取文件的前两个字节，判断文件真实类型
    $file = fopen($filename, "rb");
    $bin = fread($file, 2); // 只读前两个字节
    fclose($file);
    $strInfo = @unpack("C2chars", $bin);
    $typeCode = intval($strInfo['chars1'] . $strInfo['chars2']);
    $fileType = '';
    switch ($typeCode) {
        case 255216: $fileType = 'jpg';  break;
        case 13780:  $fileType = 'png';  break;
        case 7173:   $fileType = 'gif';  break;
        default:     $fileType = 'unknown';
    }
    return $fileType;
}

$is_upload = false;
$msg = null;
if (isset($_POST['submit'])) {
    $temp_file = $_FILES['upload_file']['tmp_name'];
    $file_type = getRealFileType($temp_file);

    if ($file_type == 'unknown') {
        $msg = '文件未知，上传失败！';
    } else {
        $img_path = UPLOAD_PATH . "/" . rand(10, 99) . date("YmdHis") . "." . $file_type;
        if (move_uploaded_file($temp_file, $img_path)) {
            $is_upload = true;
        } else {
            $msg = '上传出错！';
        }
    }
}
```

## 攻击链路

- 通过`copy 222.jpg/b+111.php 000.jpg`生成图片木马

- 上传图片木马

- 通过任意文件读取漏洞激活上传成功的图片

- 使用蚁剑（AntSword）连接目标 URL




## 拓展：

- ❌ **仅读取文件头判断类型**：`getReailFileType()` 只读前两个字节，可被图片木马绕过

- ✅ **应使用 `getimagesize()`、`finfo_file()` 等综合检测文件真实类型**

- ✅ **禁止上传可解析的后缀（如 `.php`），白名单限制扩展名**

- ✅ **将上传目录设为不可执行**
