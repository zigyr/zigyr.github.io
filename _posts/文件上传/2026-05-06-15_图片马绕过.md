## Pass-15：getimagesize() 绕过
---

```php
function isImage($filename){
    $types = '.jpeg|.png|.gif';
    if (file_exists($filename)){
        $info = getimagesize($filename);
        $ext = image_type_to_extension($info[2]);
        if (stripos($types, $ext) !== false){
            return $ext;
        } else {
            return false;
        }
    } else {
        return false;
    }
}

$is_upload = false;
$msg = null;

if (isset($_POST['submit'])){
    $temp_file = $_FILES['upload_file']['tmp_file'];
    $res = isImage($temp_file);
    if (!$res){
        $msg = "文件未知，上传失败";
    } else {
        $img_path = UPLOAD_PATH . "/" . rand(10, 99) . date("YmdHis") . "." . $res;
        if (move_uploaded_file($temp_file, $img_path)){
            $is_upload = true;
        } else {
            $msg = "上传错误";
        }
    }
}
````

### getimagesize() 函数说明

`getimagesize()` 函数返回一个包含图像信息的数组：

| 索引  | 说明                                                   |
| --- | ---------------------------------------------------- |
| 0   | 图像的宽度（像素）                                            |
| 1   | 图像的高度（像素）                                            |
| 2   | 图像类型的常量值（可用 `image_type_to_mime_type()` 转换为 MIME 类型） |
| 3   | 包含图像属性的字符串，如 `"width=500,height=300"`                |

**图像类型常量值：**

|常量值|对应类型|
|---|---|
|1|IMAGETYPE_GIF|
|2|IMAGETYPE_JPEG|
|3|IMAGETYPE_PNG|
|4|IMAGETYPE_SWF|
|5|IMAGETYPE_PSD|
|6|IMAGETYPE_BMP|

> 如果 `getimagesize()` 无法获取图像信息，返回 `false`；否则返回包含上述索引的数组。

### 漏洞利用步骤

1. 通过`copy 222.png/b+111.php 000.png`制作图片马

2. **上传图片马**到目标服务器

3. **获取上传路径**（通常回显显示）

4. 利用**文件包含漏洞include**激活木马

5. **蚁剑连接**激活后的木马 URL

### 注意事项

如果使用 `copy 111.php+222.png/b 000.png` 的顺序，可能无法解析或上传失败

- **原因**：
	- 检查机制会先检查文件头字节，再检查字节类型

- **解决方案**：
	- 手动用记事本打开图片马，将 PHP 代码移动到文件末尾即可正常上传

```php
function isImage($filename){
    // 需要开启php_exif模块
    $image_type = exif_imagetype($filename);
    switch ($image_type){
        case IMAGETYPE_GIF:
            return "gif";
            break;
        case IMAGETYPE_JPEG:
            return "jpg";
            break;
        case IMAGETYPE_PNG:
            return "png";
            break;
        default:
            return false;
            break;
    }
}
```
