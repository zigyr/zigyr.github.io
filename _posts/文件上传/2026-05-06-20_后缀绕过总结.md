## 题目
---

```php

$is_upload = false;
$msg = null;

if (isset($_POST['submit'])){
	if (file_exists(UPLOAD_PATH)){
		$deny_ext = array('一堆黑名单...');
 
		$file_name = $_POST['save_name'];
		$file_ext = pathinfo($file_name, PATHINFO_EXTENSION);
 
		if (!in_array($file_ext, $deny_ext)){
			$temp_file = $_FILES['upload_file']['tmp_name'];
			$img_path = UPLOAD_PATH . '/' . $file_name;
			if (move_uploaded_file($temp_file, $img_path)){
				$is_upload = true;
			} else {
				$msg = '上传出错';
			}
		} else {
			$msg = '禁止保持为该类型的文件';
		}
	} else {
		$msg = UPLOAD_PATH . "文件夹不存在，请手工创建";
	}
}
```


### 注：关于`$file_ext = pathinfo($file_name, PATHINFO_EXTENSION);`：


`PATHINFO_EXTENSION` 返回的是**最后一个点（`.`）之后**的所有字符，并且：

- 如果**最后一个字符是点** → 返回**空字符串** `""`

- 如果**文件名以点开头**（如 `.htaccess`）→ 返回空字符串

- **不会去除末尾空格**

- **不会解析 NTFS 数据流语法** `::$DATA`


## 0x01 绕过点：`.php` 后缀本身
---


- 上传`111.php`一句话木马

- 在下侧的`保存名称`处，写`111.php `、`111.php.`、`111.php. `、`111.php\.`

- 随后上传，访问`base_url + /upload/111.php`即可


## 0x02 绕过点：%00 截断（NULL Byte Injection）
---

- 上传一句话木马`111.php`

- bp拦截，在请求中修改**保存名称**参数为 `upload-19.php .jpg`

- 用 BurpSuite Hex 面板，选中**中间的空格**字符

- 在 Hex 编辑区将空格（`20`）改为 `00`，点击 **Apply changes**

- 发送请求

- 访问`base_url + /upload/upload-19.php`即可


## 0x03 绕过点：额外数据流`::$DATA`
---


- 上传一句话木马`111.php`

- bp拦截，在请求中修改**保存名称**参数为 `upload-19.php::$DATA`

- 发送请求

- 访问`base_url + /upload/upload-19.php`即可


**效果**：

- `move_uploaded_file()` 将文件写入为 `111.php`
- `::$DATA` 是 NTFS 的**备用数据流**（Alternate Data Stream），在文件系统中不产生独立文件
- Web 服务器若配置不当（如 Apache/Nginx 以默认模式运行），访问 `111.php::$DATA` 时会触发 PHP 解析
- 部分文件管理器（如 IIS + Windows Server）直接读取主数据流，绕过后缀检测

**注意**：`::$DATA` 在非 Windows 系统无效，渗透场景限于 Windows + IIS/Apache。
